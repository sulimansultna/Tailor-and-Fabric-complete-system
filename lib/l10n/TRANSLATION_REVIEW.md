# Translation review notes

Pashto and Dari labels are provided for the existing screens. The tailoring
terms for hip/seat, cuff, armhole, and finished sleeve openings can vary by
region and should be checked by a native speaking tailor before production
use. The database garment keys and order status values remain unchanged.

The current application has no receipt or report printing implementation to
localize or visually verify. Fabric purchases, workers, expenses, reports, and
backup/restore are placeholders in this codebase; their navigation and
placeholder messages are localized, but those workflows do not exist yet.
